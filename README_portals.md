# Portals Offers

Telegram Web App для управления офферами на маркете подарков **Portals**.

- `portals.html` — интерфейс (один файл, работает и внутри Telegram, и в браузере).
- `server.py` — бэкенд-прокси к API Portals (обходит CORS, хранит токен).

## Два режима

| Режим | Когда | Что работает |
|---|---|---|
| **Демо** | без токена | Весь UI на мок-данных. Офферы меняются только на экране. |
| **Онлайн** | задан `PORTALS_AUTH` | Реальные коллекции, флоры, баланс и офферы с биржи. |

Приложение само определяет режим: если прокси отдаёт токен — идёт в реальный
API, иначе тихо откатывается на демо. Индикатор режима — в шапке
(`● онлайн` / `● демо`).

## Запуск

```bash
# демо-режим (без токена)
python3 server.py
# → http://localhost:8080

# реальный режим
export PORTALS_AUTH="ВАШ_ТОКЕН"     # без префикса 'tma '
python3 server.py
```

## Где взять PORTALS_AUTH

1. Откройте https://web.telegram.org и запустите бота **@portals**.
2. DevTools → вкладка **Network**.
3. Найдите любой запрос к `portals-market.com` → заголовок **Authorization**.
4. Скопируйте всё, что идёт **после `tma `**, — это и есть токен.

Токен временный (живёт ~1–7 дней), потом получить заново.

## Реальные эндпоинты (через прокси `/portals-api/…`)

| Действие | Эндпоинт |
|---|---|
| Коллекции | `GET /collections` |
| Флоры | `GET /collections/floors` |
| Баланс | `GET /users/wallets/` |
| Мои офферы | `GET /offers/placed` |
| Оффер на коллекцию | `POST /collection-offers/` |
| Отмена коллекц-оффера | `POST /collection-offers/cancel` |
| Оффер на конкретный NFT | `POST /offers` |
| Отмена NFT-оффера | `POST /offers/{id}/cancel` |

## ⚠️ Важно

`portals-market.com/api` — **неофициальный внутренний API**. Он не
документирован и не поддерживается Portals, может измениться в любой момент.
Автоматические офферы могут нарушать правила площадки — используйте на свой
риск. Маппинг полей ответа сделан защитно; после первого запуска с живым
токеном стоит проверить имена полей в DevTools и при необходимости поправить
функции `mapCollection` / `mapOffer` в `portals.html`.
